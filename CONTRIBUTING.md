# Guide de contribution

Merci de l'intérêt que vous portez à ce projet ! Les contributions de la communauté sont les bienvenues.

---

## Comment contribuer ?

### 1. Signaler un bug ou proposer une fonctionnalité
Avant d'ouvrir un ticket (Issue):
- Vérifiez que le sujet n'a pas déjà été signalé dans la liste des Issues.
- Si ce n'est pas le cas, ouvrez une nouvelle Issue en détaillant au maximum :
  - La description du problème ou de la fonctionnalité souhaitée.
  - Les étapes pour reproduire le comportement (pour un bug).
  - Votre environnement (version de Java, OS, etc.).

---

### 2. Proposer une modification de code (Pull Request)

1. Créez une nouvelle branche de travail à partir de develop (ex: feature/ma-fonctionnalite ou fix/mon-correctif).
2. Développez vos modifications en conservant un code lisible et propre.
3. Commitez vos changements avec des messages clairs.
4. Poussez votre branche sur le dépôt.
5. Ouvrez une Pull Request (PR) en ciblant la branche develop.

---

## Règles de validation des PRs

- Revue de code: Chaque Pull Request sera relue avant d'être fusionnée.
- Vérifications automatiques: Assurez-vous que la compilation et les scans de sécurité (CodeQL) passent au vert sur votre PR.
- Conversations: Toutes les remarques ou discussions ouvertes sur la PR doivent être résolues avant le merge.

---

## Code de conduite

Ce projet adhère au Contributor Covenant. En participant, vous vous engagez à faire preuve de respect, de bienveillance et de courtoisie envers l'ensemble des contributeurs.
